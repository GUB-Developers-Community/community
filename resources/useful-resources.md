# Useful Learning Resources

This list focuses on resources that are useful for self-study and community workshops. Check each service's current terms and documentation before relying on it.

## Foundations

- [MDN Web Docs](https://developer.mozilla.org/) — practical web platform documentation.
- [The Missing Semester of Your CS Education](https://missing.csail.mit.edu/) — command-line and developer-tool fundamentals.
- [freeCodeCamp](https://www.freecodecamp.org/) — guided interactive lessons and projects.
- [CS50](https://cs50.harvard.edu/) — introductory computer science courses and problem sets.

## Git and Collaboration

- [Pro Git](https://git-scm.com/book/en/v2) — detailed Git reference and tutorials.
- [GitHub Skills](https://skills.github.com/) — hands-on GitHub exercises.
- [GitHub Docs](https://docs.github.com/) — official documentation for collaboration and open source.

## Programming Practice

- [Exercism](https://exercism.org/) — language practice with community mentoring.
- [Codeforces](https://codeforces.com/) — competitive programming problems and contests.
- [LeetCode](https://leetcode.com/) — algorithm and data-structure practice.

## Python and Data

- [Python Documentation](https://docs.python.org/3/) — official language documentation.
- [Automate the Boring Stuff with Python](https://automatetheboringstuff.com/) — practical automation projects.
- [Kaggle Learn](https://www.kaggle.com/learn) — short courses for data and machine learning.

## Choosing Resources Well

Prefer material that is current, explains concepts rather than only copying code, includes exercises, and states its assumptions. Keep notes on what you tried, what failed, and how you verified the result.
