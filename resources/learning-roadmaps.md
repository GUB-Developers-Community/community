# Learning Roadmaps

Use these beginner-to-intermediate roadmaps as a guide. Move at your own pace.

## 1) Web Development

### Beginner
- HTML, CSS, JavaScript basics
- Git and GitHub fundamentals
- Build static pages and simple portfolio projects

### Intermediate
- JavaScript ES6+, DOM, and APIs
- One frontend framework (React/Vue/Angular)
- Backend basics (Node.js/Express or similar)
- Database basics (SQL + one NoSQL option)

### Practice
- Build a to-do app, blog app, and small full-stack project

## 2) AI/ML

### Beginner
- Python programming fundamentals
- Math basics: linear algebra, probability, statistics
- Data handling with NumPy and pandas

### Intermediate
- Machine learning with scikit-learn
- Model evaluation and feature engineering
- Intro to deep learning with TensorFlow or PyTorch

### Practice
- Build mini projects: classification, regression, and text analysis

## 3) Competitive Programming

### Beginner
- Language fundamentals (C++/Java/Python)
- Time and space complexity
- Basic data structures: arrays, strings, stacks, queues

### Intermediate
- Trees, graphs, sorting/searching, recursion, DP
- Problem-solving on online judges
- Contest strategy and debugging speed

### Practice
- Solve problems regularly and review editorials

## 4) Software Engineering

### Beginner
- Programming fundamentals and OOP
- Git workflow and team collaboration
- Writing readable and testable code

### Intermediate
- System design basics
- Testing (unit/integration)
- CI/CD concepts and release workflow

### Practice
- Contribute to open-source and build team projects
