# Learning Roadmaps

Use these roadmaps as flexible guides rather than strict checklists. Choose one direction, build small projects, and revisit fundamentals as your goals change.

## Web Development

1. Learn HTML, CSS, and JavaScript fundamentals.
2. Practice responsive layouts, accessibility, and browser tools.
3. Learn Git and GitHub through small collaborative projects.
4. Choose a frontend framework or a backend language.
5. Build and deploy a complete application.

## Python and Automation

1. Learn Python syntax, functions, modules, and virtual environments.
2. Practice file handling, HTTP requests, testing, and error handling.
3. Automate a useful personal or student workflow.
4. Learn a framework or library relevant to your goal.
5. Package, document, and share the project.

## Data and AI

1. Strengthen Python, statistics, and data-wrangling fundamentals.
2. Learn NumPy, pandas, visualization, and responsible data handling.
3. Study machine-learning concepts with small, explainable datasets.
4. Evaluate models with appropriate metrics and honest limitations.
5. Build a documented project that solves a real problem.

## Competitive Programming

1. Become comfortable with one programming language and its standard library.
2. Practice complexity analysis, implementation, and debugging.
3. Study arrays, strings, sorting, searching, recursion, and graphs.
4. Solve problems regularly and review alternative solutions.
5. Join practice sessions or contests and discuss your reasoning.

## Open Source

1. Learn Git branches, commits, pull requests, and issue tracking.
2. Start with documentation, tests, or small bug fixes.
3. Read the contribution guide and project conventions.
4. Ask focused questions and explain your changes clearly.
5. Maintain your contribution by responding to review feedback.

## A Practical Study Loop

Set a small weekly goal, learn from one reliable source, build something, write down what you learned, and share it with another learner. Consistency is more valuable than trying to master everything at once.
