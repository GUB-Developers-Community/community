# Events

This section documents community activities such as workshops, hackathons, coding sessions, and meetups.

## Event Record Format

When adding an event summary, create a markdown file in this folder using this format:

`YYYY-MM-DD-event-name.md`

Example: `2026-01-20-intro-to-git-workshop.md`

## Suggested Template

```md
# Event Title

- Date:
- Type: Workshop / Hackathon / Meetup / Study Session
- Organizers:
- Audience:

## Agenda
- 

## Key Takeaways
- 

## Resources Shared
- 

## Next Steps
- 
```

## Notes

- Keep event documentation concise and clear.
- Share useful learning outcomes and resources.
- Avoid adding personal contact details.
