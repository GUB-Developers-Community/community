# Members

This section is for community members who want to introduce themselves.

## How to Add Your Introduction

1. Create a new markdown file in this folder using your GitHub username.
   - Example: `your-username.md`
2. Use this simple format:

```md
# Your Name

- GitHub: @your-username
- Interests: Web Development, AI/ML, Competitive Programming
- Skills: Beginner/Intermediate/Advanced
- Learning Goals: What you want to learn in this community
- Collaboration: What kind of projects you want to join
```

3. Open a pull request with your file.

## Guidelines

- Keep your intro short and respectful.
- Do not include sensitive personal information.
- Encourage collaboration and learning.
