# Community Members

The GUB Developers Community is built by students who learn, create, and support one another. You do not need to be an expert or have prior open-source experience to participate.

## How to Participate

- Introduce yourself in a GitHub Discussion or community event.
- Share what you are learning and ask focused questions.
- Join a project, review documentation, or suggest an improvement.
- Help another learner when you can.
- Add your name below when you have contributed and want to be listed.
