# GUB Developers Community

Welcome to the **GUB Developers Community** repository — a student-led space for students of **Green University of Bangladesh (GUB)** to learn, build, and collaborate together.

> This is a student initiative and **not an officially approved university organization**.

## Mission

Create a beginner-friendly and collaborative developer community where students can:
- learn modern programming skills,
- practice open-source collaboration,
- build useful projects,
- and support each other through peer learning.

## Community Goals

- Help students get started with programming and software development.
- Encourage open-source contributions and team projects.
- Share trusted learning resources and roadmaps.
- Host and document student-driven technical events.
- Build a portfolio of community-driven projects.

## How to Join

1. Star and watch this repository.
2. Read the [Code of Conduct](CODE_OF_CONDUCT.md).
3. Check [CONTRIBUTING.md](CONTRIBUTING.md) to start contributing.
4. Introduce yourself in [members/README.md](members/README.md).
5. Open issues for ideas, improvements, and resources.
